## Paso 4: Colocar la foto para verificar si perteneces a la institución educativa
Saldrá esta pestaña emergente el cual pide que coloques la foto de perfil
> [!IMPORTANT]
> Primero saldrá una lista de opciones elegir la del carnet institucional, ya que la verificación para el carnet es buena y es más probable que sea aceptada casi al instante. 

> [!TIP]
> Para que te acepten el carnet ya que el carnet no presenta fecha en ninguna parte se debe colocar el recibo de pago debajo y alado el carnte encima, lo importante es que se vea la fecha del año actual y del semestre actual y encima el carnet institucional como se ve en la siguiente imagen
